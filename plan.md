# Plan

Three tabs. All output is A4 PDF.

## Tab 1: one page dungeon

- Import a map image on an A4 canvas. Portrait or landscape.
- Add a numbered pin by right click on the map.
- Move or remove a pin. The tool renumbers the other pins and their legends.
- Legends show in the free space. They never touch the map.
- Possible text blocks:
  - general information
  - dwellers
  - legends.
- Each block has a title, a subtitle, bullet lists and text. Each block has a colour and a type in the code
- Text overflow adds a new page.

## Tab 2: card maker

- Add a title, a subtitle and a text to a card.
- Card size is 60 mm by 80 mm.
- Collect the cards for print. The cards fill the A4 pages.

## Tab 3: token maker

- Import a picture. Make round tokens.
- Token size is 2.5 cm, 5 cm or 7.5 cm.
- Move and resize the picture in the token.
- Add a coloured ring. The ring shows above the picture.
- Collect the tokens for print. The tab 2 rules apply.

## MVP

A4 only.
